从旧版升级前，请阅读[升级说明](https://github.com/rockie/vslight/blob/1.135.06567/docs/vslight-migration.md#从旧版-vslight-升级)。旧 Chat 历史、MCP 配置和凭据仍保留在磁盘上，新版不再提供内置访问入口。

基于 VS Code 1.135.0，本次发布适用于 **macOS 12+、Apple Silicon（arm64）**。

## 本次变化

- 物理移除内置 Chat、语言模型、MCP、语音及 agent-host 服务，进一步缩小本地编辑器体积。第三方扩展仍可提供自己的 AI 实现；依赖已移除内置服务的功能不可用。
- 移除 Integrated Browser 和 Simple Browser。普通网页及 localhost 默认在系统浏览器中打开，第三方链接 opener 机制保留。
- 保留编辑、文件、搜索、Git、终端、任务、Open VSX 扩展市场、Webview 和 Markdown 预览。
- 独立 Mermaid 编辑器保留 ELK、tidy-tree 和 ZenUML；修复退出、重启后的编辑器与 Markdown 预览状态恢复。
- 清理终端中已退休命令的默认按键过滤项，保留普通终端操作和用户覆盖。
- macOS 原生资源保留英文、简体中文和繁体中文，其他原生语言回退英文；工作台语言包仍可使用。

## 升级注意

- `vslight chat` 和 `vslight --add-mcp` 会提示不可用并以状态码 1 退出；打开名为 chat 的文件可使用 `vslight -- chat`。
- 稳定 Chat/LM/MCP API 保留兼容对象，但不提供内置能力：模型和工具列表为空，注册不生效，调用工具返回 `LanguageModelError.NotFound`。
- 本次交付与验收范围为 macOS arm64。
